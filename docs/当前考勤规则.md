# 当前考勤规则

规则版本：2026-08-06

本页说明当前版本程序实际执行的统计口径。原始制度中尚未实现或仍待确认的内容，不视为已经生效。

## 数据范围

- 输入必须是钉钉导出的完整 `.xlsx` 考勤报表。
- 报表必须包含 `打卡时间`、`原始记录`、`月度汇总`、`每日统计` 四张工作表。
- 考勤月份从 `每日统计` 的日期自动读取，不需要手工选择。
- 员工优先按工号关联；工号缺失时才使用钉钉 UserId 或姓名回退。
- “不参与考勤人员”会从明细、汇总和异常表中完全排除。

## 出勤与加班

| 项目 | 当前计算方式 |
| --- | --- |
| 本应出勤 | 有有效班次且班次不为“休息”的日期数 × 8 小时 |
| 正常出勤 | `max(本应出勤 - 全部请假 - 旷工, 0)` |
| 实际出勤 | 正常出勤 + 平时加班 + 周末加班 + 法定加班 |
| 平时加班 | 读取钉钉月度汇总的工作日加班小时 |
| 周末加班 | 读取钉钉月度汇总的休息日加班小时 |
| 法定加班 | 读取钉钉月度汇总的节假日加班小时 |

程序默认钉钉已经完成加班审批和时长核定，不再自行扣除午休，也不重新应用“最小加班单位”。

三类餐补特殊人员分组都不计算加班。命中配置后，每日加班和月度加班汇总均为 0，实际出勤也不包含加班。“弹性到岗（8:30 分界）”分组只改变迟到、早退判断，不清零加班。

## 请假与旷工

- 年假、病假、事假、调休和哺乳假按钉钉汇总小时计算。
- 婚假、产假、陪产假、丧假和例假按天数乘以 8 小时。
- 育儿假和产检假先按同一流程去重，再统计流程总时长。
- 跨日请假不会把同一流程总时长重复累计；每天最多分配 8 小时。
- 旷工小时为每日旷工天数合计乘以 8。

## 每日明细符号

| 状态 | 符号 | 状态 | 符号 |
| --- | --- | --- | --- |
| 正常出勤 | `√` | 休息/未排班 | `☆` |
| 迟到 | `D` + 分钟 | 早退 | `Z` + 分钟 |
| 病假 | `△` + 小时 | 事假 | `O` + 小时 |
| 旷工 | `X` + 小时 | 年休假 | `N` + 小时 |
| 婚假 | `H` + 小时 | 产假/陪产假 | `M` + 小时 |
| 丧假 | `S` + 小时 | 出差 | `C` |
| 育儿假 | `Y` + 小时 | 哺乳假 | `B` + 小时 |
| 产检假 | `P` + 小时 | 调休 | `T` + 小时 |

- 一般人员只有钉钉打卡结果明确标记为“迟到”或“早退”时，程序才计算分钟数。
- 弹性到岗人员在 08:30（含）之前到岗时以 17:30 为下班时间；08:30 之后到岗不记迟到，并以 18:00 为下班时间。早退按当天对应的下班时间判断。
- 上班或下班缺卡时，当日标记会追加“缺卡”。
- 非工作日标记为灰色。2026 年已内置法定节假日和调休工作日数据；其他年份如未内置年度数据，会回退为公历周六、周日并在生成结果中提示。

## 出差与所属公司

- 出差天数按月度每日结果中包含“出差”的日期数统计。
- 所属公司优先沿用模板中的历史员工映射。
- 未找到历史映射时：考勤组包含“滁州”记为“滁州”，包含“昆山”记为“KSFAE”，其他记为“JSFAE”。

## 异常与绩效扣分

| 异常 | 统计方式 |
| --- | --- |
| 未打卡 | 同一天上班、下班均缺卡，或排班日旷工且完全没有打卡 |
| 未签到 | 仅上班缺卡 |
| 未签退 | 仅下班缺卡 |
| 迟到/早退 1-10 分钟 | 每次记 1 次 |
| 迟到/早退 11-30 分钟 | 每次记 1 次 |
| 迟到/早退 31-120 分钟 | 累加分钟数 |
| 不在范围内打卡 | 原始记录包含“当前不在可打卡的时间范围” |

```text
绩效扣分 = 未打卡 + 未签到 + 未签退
         + 1-10 分钟次数 + 不在范围内打卡次数
         + 11-30 分钟次数 × 2
         + ceil(31-120 分钟累计分钟数 ÷ 30)
```

超过 120 分钟的迟到或早退当前不进入上述分档。无法从班次和实际打卡计算分钟数的记录不会计入扣分，并会在生成结果中提示。

## 当前暂未计算

以下字段会保持空白，不会用 0 代替未知结果：

- **餐补次数**：已接入计算。10:00 整仍计工作日出勤餐补；无审批不计加班餐补，有审批时审批时长与实际打卡加班时长取较短值；跨日归属加班开始日。周末/节假日按上午至 12:00、13:00-19:30、19:30-24:00 三个有效段分别满 2 小时记 1 次，12:00-13:00 午休不计。工作日 24:00 合计 2 次；特殊人员按各自口径计算。
- **年假剩余小时**：钉钉报表不包含期初余额、发放、调整和结转数据。

年假余额单元格使用浅黄色标记，表示需要补充期初余额后才能计算。餐补已计算并写入数值（包括明确的 0）。
