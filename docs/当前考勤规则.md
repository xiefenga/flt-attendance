# 当前考勤规则

规则版本：2026-08-09

本页说明当前版本程序实际执行的统计口径。原始制度中尚未实现或仍待确认的内容，不视为已经生效。

## 数据范围

- 输入必须是钉钉导出的完整 `.xlsx` 考勤报表。
- 报表必须包含 `打卡时间`、`原始记录`、`月度汇总`、`每日统计` 四张工作表。
- 考勤月份从 `每日统计` 的日期自动读取，不需要手工选择。
- 员工优先按工号关联；工号缺失时才使用钉钉 UserId 或姓名回退。
- “不参与考勤人员”会从明细、汇总和异常表中完全排除。

## 出勤与加班

| 项目 | 当前计算方式 |
| --- | --- |
| 本应出勤 | 普通人员按有效班次且班次不为“休息”的日期数 × 8 小时；六天制人员按各自每日小时数计算 |
| 正常出勤 | `max(本应出勤 - 全部请假 - 旷工, 0)` |
| 实际出勤 | 正常出勤 + 平时加班 + 周末加班 + 法定加班 |
| 平时加班 | 读取钉钉月度汇总的工作日加班小时 |
| 周末加班 | 读取钉钉月度汇总的休息日加班小时 |
| 法定加班 | 读取钉钉月度汇总的节假日加班小时 |

程序默认钉钉已经完成加班审批和时长核定，不再自行扣除午休，也不重新应用“最小加班单位”。

三类餐补特殊人员分组都不计算加班。命中配置后，每日加班和月度加班汇总均为 0，实际出勤也不包含加班。“弹性到岗（8:30 分界）”分组只改变迟到、早退判断，不清零加班。

应用不内置特殊人员名单，首次运行时各分组为空。原默认名单已外置为 [`考勤设置默认名单.json`](../examples/settings/考勤设置默认名单.json)，可在设置中导入；当前配置也可以导出为 JSON 备份。

“不打卡但有餐补”人员不依赖钉钉的打卡或每日排班记录，按在职区间内的法定工作日每天 8 小时计算出勤基数；请假、旷工仍按统一规则扣减。因此其实际出勤为 `法定工作日数 × 8 - 请假小时 - 旷工小时`（最低为 0），且不增加任何加班小时。

六天工作制人员按周一至周六计算正常工作日，不统计任何加班；平时、周六、周日和法定节假日的每日及月度加班均为 0。法定节假日不计入应出勤日。外置示例名单包含：

| 人员 | 每日应出勤 | 餐补 | 加班 |
| --- | ---: | ---: | --- |
| 廖传兰 | 8 小时 | 不统计 | 全部不统计 |
| 廖传霞 | 4 小时 | 不统计 | 全部不统计 |

两人的工号在当前样例中为空，因此外置示例配置按姓名匹配；导入后可在设置中重新配置。

## 请假与旷工

- 年假、病假、事假、调休和哺乳假按钉钉汇总小时计算。
- 婚假、产假、陪产假、丧假和例假按天数乘以每日应出勤小时数；普通人员和六天制 8 小时人员按 8 小时、六天制 4 小时人员按 4 小时换算。
- 育儿假和产检假先按同一流程去重，再统计流程总时长。
- 跨日请假不会把同一流程总时长重复累计；每天最多分配 8 小时。
- 旷工小时为每日旷工天数合计乘以每日应出勤小时数；普通人员和六天制 8 小时人员按 8 小时、六天制 4 小时人员按 4 小时换算。

## 每日明细符号

| 状态 | 符号 | 状态 | 符号 |
| --- | --- | --- | --- |
| 正常出勤 | `√` | 休息/未排班 | `☆` |
| 迟到 | `D` + 分钟 | 早退 | `Z` + 分钟 |
| 病假 | `△` + 小时 | 事假 | `O` + 小时 |
| 旷工 | `X` + 小时 | 年休假 | `N` + 小时 |
| 婚假 | `H` + 小时 | 产假/陪产假 | `M` + 小时 |
| 丧假 | `S` + 小时 | 出差 | `C` |
| 育儿假 | `Y` + 小时 | 哺乳假 | `B` + 小时 |
| 产检假 | `P` + 小时 | 调休 | `T` + 小时 |

- 一般人员只有钉钉打卡结果明确标记为“迟到”或“早退”时，程序才计算分钟数。
- 弹性到岗人员在 08:30（含）之前到岗时以 17:30 为下班时间；08:30 之后到岗不记迟到，并以 18:00 为下班时间。早退按当天对应的下班时间判断。
- 上班或下班缺卡时，当日标记会追加“缺卡”。
- 非工作日标记为灰色。2026 年已内置法定节假日和调休工作日数据；其他年份如未内置年度数据，会回退为公历周六、周日并在生成结果中提示。

## 出差与所属公司

- 出差天数按月度每日结果中包含“出差”的日期数统计。
- 入职或离职名单命中时，所属公司优先使用名单中的“所属公司”。
- 名单未命中时，所属公司沿用模板中的历史员工映射。
- 未找到历史映射时：考勤组包含“滁州”记为“滁州”，包含“昆山”记为“KSFAE”，其他记为“JSFAE”。

## 异常与绩效扣分

| 异常 | 统计方式 |
| --- | --- |
| 未签到 | 没有上班卡，按次数统计；整天无打卡也记 1 次 |
| 未签退 | 没有下班卡，按次数统计；整天无打卡也记 1 次 |
| 迟到/早退 1-10 分钟 | 人事行政部每次均统计；其他部门每人每月前 2 次豁免，只统计超出部分 |
| 迟到/早退 11-30 分钟 | 每次记 1 次；为避免与下一档重叠，内部计算范围为 11-29 分钟 |
| 迟到/早退 30-120 分钟 | 累加分钟数，恰好 30 分钟归入本档 |
| 不在范围内打卡 | 原始记录包含“当前不在可打卡的时间范围” |

```text
绩效扣分 = 未签到 + 未签退
         + 1-10 分钟超出豁免后的次数 + 不在范围内打卡次数
         + 11-30 分钟次数 × 2
         + ceil(30-120 分钟累计分钟数 ÷ 30)
```

异常明细表不再输出“未打卡（次）”列。备注只写入已被前面统计字段计数的异常；非人事行政部被豁免的前 2 次 10 分钟内迟到/早退不写入备注。超过 120 分钟的迟到或早退当前不进入上述分档。无法从班次和实际打卡计算分钟数的记录不会计入扣分，并会在生成结果中提示。

## 餐补与入离职区间

- **餐补次数**：已接入计算。10:00 整仍计工作日出勤餐补；无审批不计加班餐补，有审批时审批时长与实际打卡加班时长取较短值；跨日归属加班开始日。周末/节假日按上午至 12:00、13:00-19:30、19:30-24:00 三个有效段分别满 2 小时记 1 次，12:00-13:00 午休不计。工作日 24:00 合计 2 次；特殊人员按各自口径计算。餐补会写入数值，明确无餐补时写 `0`。
- **入离职区间**：已接入计算。工作簿包含“入职名单”和“离职名单”时，入职日和离职日均计入在职区间；入职日前、离职日后不计应出勤、餐补和异常。普通人员入职当天为工作日时，即使打卡异常仍记 1 次出勤餐补（出差、居家办公除外）。

## 当前暂不统计

- **年假剩余小时**：现阶段不统计，报表保留该列但所有人员的数据保持空白，不写 `0`，也不根据本月已休年假反推余额。年假余额单元格继续使用浅黄色标记。
